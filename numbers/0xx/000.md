## 数学的性質

- **素因数分解**: $0$
- **各位の和**: 0
- **フラグの解説**（概要のフラグに対応。機械導出・検算済み）:
  - **平方数**: 整数の 2 乗で表される数。$0 = 0^2$。
  - **立方数**: 整数の 3 乗で表される数。$0 = 0^3$。
  - **三角数**: 三角数列の初項（$T_0 = 0$）とされる。
  - **フィボナッチ数**: フィボナッチ数列（0, 1, 1, 2, 3, 5, 8, …。隣接 2 項の和で定まる）の項。
  - **ナルシシスト数**: 各位を桁数乗して足すと自身に戻る数（アームストロング数）。（OEIS [A005188](https://oeis.org/A005188)） コメント（OEIS の当該数列より和訳・要約、CC BY-SA 4.0）: 有限数列で全 89 項。最大は 115132219018763992565095597973971522401。
  - **トリボナッチ数**: 直前 3 項の和で定まる数列（0, 0, 1, 1, 2, 4, 7, 13, …）の項。（OEIS [A000073](https://oeis.org/A000073)） コメント（OEIS の当該数列より和訳・要約、CC BY-SA 4.0）: 3 以下の部分のみからなる合成（順序付き分割）の個数でもある。
  - **テトラナッチ数**: 直前 4 項の和で定まる数列（0, 0, 0, 1, 1, 2, 4, 8, …）の項。（OEIS [A000078](https://oeis.org/A000078)） コメント（OEIS の当該数列より和訳・要約、CC BY-SA 4.0）: 4 以下の部分のみからなる合成の個数でもある。
  - **ヤーコプスタール数**: $J_k = J_{k-1} + 2J_{k-2}$ で定まる数列（0, 1, 1, 3, 5, 11, …）の項。（OEIS [A001045](https://oeis.org/A001045)） コメント（OEIS の当該数列より和訳・要約、CC BY-SA 4.0）: $2 \times (k-1)$ の長方形を 1×2 ドミノと 2×2 正方形で敷き詰める方法の数でもある。
  - **ペラン数**: $P_k = P_{k-2} + P_{k-3}$ で定まる数列（3, 0, 2, 3, 2, 5, …）の項。（OEIS [A001608](https://oeis.org/A001608)） コメント（OEIS の当該数列より和訳・要約、CC BY-SA 4.0）: $p$ が素数なら第 $p$ 項は $p$ で割り切れる。逆は成り立たず、最小の合成数の反例は $521^2$。

### 数秘術・エンジェルナンバー（機械導出）

- **数秘術**: 0 は伝統的な数秘術では還元の対象外とされることが多く、『無』や『可能性そのもの』を表すとされる（[数秘術](https://ja.wikipedia.org/wiki/%E6%95%B0%E7%A7%98%E8%A1%93)参照）

### 吉凶・伝承・名数・語呂（キュレーション）

- **伝承・神話・名数**: 『無』を表す数としてインドで概念化され、哲学・宗教でも『空（くう）』と結び付けて語られることがある。（参照: https://ja.wikipedia.org/wiki/0）
