# 進捗レポート（2026-08-07）— 数列フラグの拡充と情報源ポリシーの整備

## 目的

`CheatSheet-of_Numbers` の各ページに、これまで扱っていなかった**数列への所属**（多角数・幸運数・ウラム数・各種特殊素数など）を追加し、あわせて外部情報源の採否基準を `AGENTS.md` に明文化する。

きっかけは「https://number-pedia.com/ から情報を推敲する」という依頼だったが、調査の結果、方針を変更した（下記）。

## 情報源の調査結果（重要）

### number-pedia.com は取り込み不可

- 同サイトは**純粋な数学（数列所属）のみ**を扱い、本リポジトリの『数秘・占術・文化のいわれ』に相当する内容は**一切ない**。
- [利用規約](https://number-pedia.com/terms-of-service/)第五条が、事前同意なき **複製・再生・保管（4号）** と **プログラムによるアクセス・スクレイピング（5号）** を明示的に禁止している。
- → 取得・転載は行わず、**「どの数列を扱うべきか」の目録として人手で参照するに留めた**。数列の所属自体は著作物ではない事実なので、判定は自前計算に置き換えた。

### 代替として OEIS を採用

- OEIS は **CC BY-SA 4.0**（2023-02-24 承認の EULA §2）で、本リポジトリのライセンスと完全に一致する。
- ただし利用規約 §10(d)(f) と robots.txt（`Disallow: /search`, `Crawl-Delay: 10`）が自動アクセスを禁止しているため、**`oeis.org` をバッチで叩かない**。データが必要なときは GitHub 公式ミラー `oeis/oeisdata` を clone する。
- 今回は各数列に **A 番号のリンクを添えるのみ**（リンクは規約上問題なし）。

### その他の候補（`AGENTS.md` の表に反映済み）

- **採用可（未着手）**: ja.Wiktionary の字源（CC BY-SA 4.0）、青空文庫の PD 本文、NDL の保護期間満了資料（PDL1.0 は CC BY 互換）
- **不可**: Numbers Aplenty（ライセンス表示なし＝全権利留保）、Prime Curios!（GPLv3 で CC BY-SA と非互換）、コトバンク（商用利用禁止）
- 「数字の文化的いわれ」を再利用可能ライセンスで公開している日本語専用サイトは**事実上存在しない**。Wikimedia + パブリックドメインの組み合わせが唯一の合法ルート。

## 変更点の要約

`tools/generate_numbers.py` に約 590 行を追加し、**60 系列**の所属判定を自前実装した。

- **多角数**（五角数〜二十角数）と**中心つき多角数**（中心つき三角数〜二十角数）は、概要のフラグが長くなりすぎるため**各 1 フラグに集約**し、該当する具体名と第何項かを解説側に列挙する。
- 立体数: 三角錐数 / 四角錐数 / 五角錐数 / 五胞体数 / 星型八面体数 / ケーキ数 / 矩形数
- 個別: 幸運数 / ウラム数 / スミス数 / ナルシシスト数 / ズッカーマン数 / 多冪数 / アキレス数 / プロス数 / レイランド数 / ハミング数 / カプレカ数 / 疑似完全数 / 完全トーシェント数 / 調和数（オア数） / 超過剰数 / トーシェント数 / ファクトリオン / 交互階乗 / ベル数 / モツキン数 / モンモール数 / オイラー数 / タンジェント数 / フェルマー数 / ユークリッド数 / クンマー数 / カレン数 / ウッダル数 / キャロル数 / キネア数 / サービット数 / トリボナッチ数 / テトラナッチ数 / ヤーコプスタール数 / ペラン数
- 素数系: ピタゴラス素数 / 平衡素数 / スーパー素数 / オイラー素数 / キュバン素数 / 陳素数 / 置換可能素数 / 左切り捨て可能素数 / 右切り捨て可能素数 / メルセンヌ素数 / ワグスタッフ素数 / NSW 素数

既存フラグ（半素数・不足数・ハーシャッド数など）と重複する名前は `sequence_flag_details(n, already)` で除外し、**解説がセクション内で重複しない**という既存ルールを維持している。

## 検算

1. **OEIS 公表値との突き合わせ**: 61 系列について 0〜999 の全域を照合し、**不一致 0 件**。
2. うち判定が微妙な 2 件（ズッカーマン数 A007602、左切り捨て可能素数 A024785）は **OEIS の b-file と完全一致**を確認（当初の手入力参照値のほうが誤りだった）。
3. **A 番号と数列名の対応**を GitHub ミラー `oeis/oeisdata` の `%N` 行で 69 件照合し、**誤り 0 件**。
4. 生成後チェック: `check_internal_links.py` で **Missing links: 0**（1013 ファイル / 9780 リンク）、Liquid 危険パターン `{{` `{%` **0 件**、KaTeX の未閉じ `$` **0 件**。
5. 差分の全削除行が「旧 `**フラグ（数学）**:` 行」であることを確認済み（Wikipedia 引用行の増減は ±0 で、既存コンテンツの欠落なし）。

### 検算で見つけて直したもの

- **陳素数**: 半素数判定の演算子優先順位バグ（`A or B and C`）と、素因数の重複を数えていなかった誤り。2, 7, 23 などが漏れていた。
- **NSW 素数**: 半 companion ペル数の**奇数番項のみ**が NSW 数。全項を採っていたため 3, 17, 577 が誤って混入していた。
- **六芒星数と中心つき十二角数は同一数列**（ともに A003154）。二重にフラグが立つのを避け、中心つき側のラベルを「中心つき十二角数（＝六芒星数）」とした。
- **調和数**は日本語だと $H_n = 1 + 1/2 + \cdots + 1/n$ と紛らわしいため「調和数（オア数）」に改称し、解説で別物である旨を明記。

## 追記（同日）: Wikipedia 接続の再確認と海外リソース調査

### Wikipedia 接続

- Cowork のサンドボックスから **Wikimedia 系ドメイン（ja/en.wikipedia, wikidata, api.wikimedia.org, dumps.wikimedia.org）への直接 HTTP 接続はすべてプロキシで遮断**（403）されていることを確認した（github.com / pypi.org は通る）。閲覧ツール経由では本文を取得できるが、`generate_numbers.py`（urllib 直叩き）は動かせない。
- そのため生成は引き続き `--offline`（キャッシュ）で実施している。**ローカル環境（Windows）で以下を実行すればキャッシュが更新される**:

  ```powershell
  python tools/generate_numbers.py --wikipedia-sections --refresh-wikipedia --refresh-wikipedia-sections --refresh-wikidata
  python tools/check_internal_links.py
  ```

### 海外リソースの和訳（翻案）収録の調査結果

和訳は翻案にあたるため、原文ライセンスが翻案・再配布を許すことが条件。結論として **CC BY-SA 系と PD の二系統のみ収録可能**。`AGENTS.md` の情報源表に追記した。

- **採用可（推奨順）**:
  1. **OEIS %C コメントの和訳** — CC BY-SA 4.0。EULA §3 が帰属方法を明記しており最も安全。データは GitHub `oeis/oeisdata` を clone（`oeis.org` は叩かない）
  2. **zh.wikipedia の数字文化記事**（四の忌避・八の吉祥など）の和訳 — 既存 Wikipedia ワークフローと同一
  3. **en.wiktionary / en.wikiquote** の語源・引用の和訳 — 同じ CC BY-SA 4.0。取り込み時にページフッターを目視確認
  4. **PD 古典の翻案** — Westcott『Numbers: Their Occult Power and Mystic Virtues』(1911, sacred-texts)、Conant『The Number Concept』(1896, PG #16449)、Dudeney『Amusements in Mathematics』(1917, PG #16713) など
- **不可**: Wolfram MathWorld（全権利留保を FAQ で明記）、Number Gossip（ライセンス表示を確認できず全権利留保扱い）
- 和訳収録時の出典表記テンプレートを `AGENTS.md` に追加した。
